# CUSTOMER_SUPPORT_INSIGHTS_PLATFORMgh 

An end-to-end data science platform that unifies customer-service interactions
across voice, chat, email, chatbot, and social channels. It uses NLP and machine
learning to identify contact drivers, sentiment, quality issues, and escalation
risk, then presents insights through dashboards and APIs.

## Objectives

- Unify omnichannel customer-support interaction data.
- Analyze contact reasons, customer sentiment, and conversation topics.
- Measure contact-centre KPIs such as FCR, AHT, escalation rate, and CSAT.
- Predict escalation or repeat-contact risk.
- Forecast contact volume by channel and intent.
- Provide dashboards for CX, operations, QA, and agent-coaching teams.

## Tech Stack

- Python, pandas, DuckDB/PostgreSQL
- dbt Core
- Hugging Face Transformers, spaCy, sentence-transformers
- scikit-learn, XGBoost, MLflow
- FastAPI
- Streamlit and Plotly
- Docker and GitHub Actions
